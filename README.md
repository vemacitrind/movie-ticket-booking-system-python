# Movie Ticket Booking System (CLI-Based)

A CLI-based movie ticket booking system built using Python that allows users to book movie tickets, view available movies, and manage bookings with a simple console-based interface.

## Features
- User Registration & Login
- Movie Listings
- Seat Selection
- Ticket Booking
- Payment Simulation
- Admin Panel for Managing Movies and Bookings

## Technologies Used
- Python
- MySQL

## Installation

### Prerequisites
- Python installed (version 3.x recommended)
- MySQL installed and running

### Steps to Install
1. Clone the repository:
```bash
git clone https://github.com/vemacitrind/movie-ticket-booking-system-python.git
cd movie-ticket-booking-system-python
```

2. Install Required Modules:
```bash
pip install mysql-connector-python rich termcolor pwinput numpy
```

3. Configure MySQL Database:
- Create a database named `moviedb.sql`
- Import the provided SQL file into the database
- Update database connection credentials in the project files if necessary

4. Run the Application:
```bash
python main.py
```
